# AGENTS.md

Personal dotfiles for macOS and Arch (incl. Omarchy), managed with Stow and `make`.
This file exists because agent tools read it by name; the content lives in one place:

- **Conventions** (style, tests, commits, PRs) → [OPERATING.md#contributing-and-conventions](OPERATING.md#contributing-and-conventions)
- **Commands** (`make` targets, verification) → [OPERATING.md#daily-operations](OPERATING.md#daily-operations)
- **Overview** → [README.md](README.md)

Hard rule: run `make verify` before pushing. There is no CI; that is the gate.
